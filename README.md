# Summertime

**Commit together. Settle together.**

Summertime lets competing importers reserve space in a shared shipping container on Canton without seeing each other's volumes or identities. Each importer locks USDCx against a forwarder-signed capacity reservation. If the container fills before the deadline, every payment settles to the forwarder in one atomic transaction. If it doesn't, every importer's funds are released and eligible importers share a failure bonus the forwarder posted upfront.
